# 比赛评分标准对照

> 比赛评分权重：AI 深度 35% · 创新性 25% · 前端质量 10% · 实用性 10% · 用户体验 10% · 社会价值 10%

| 评分项 | 权重 | 本项目对应实现 |
|---|---|---|
| **AI 技术深度** | 35% | 多智能体协作 · CRAG 自我修正检索 · 自主工具调用（计算器/时间/ArXiv）· 本地知识库(BM25) · DeepSeek 流式生成 · SSE 实时编排 · 预留向量检索升级 |
| **创新性** | 25% | ① **实时「思考流」可视化**；② **证据分级 + 学术争议检测**；③ **研究空白挖掘**——从 Limitations 自动生成未来方向；④ **人机协同**——研究中途插入指令实时调整方向 |
| **前端质量** | 10% | TypeScript 全量类型 · 模块化组件 · 清晰分层 · Tailwind v4 设计系统 · 无冗余依赖 |
| **实用性** | 10% | 直击学生/研究者的真实痛点：文献综述耗时、找研究空白难 · 支持上传本地文献建立个人知识库 |
| **用户体验** | 10% | 玻璃态沉浸式驾驶舱 · 流式动画 · 三栏信息架构 · 示例问题一键填充 · Markdown 报告排版 |
| **社会价值** | 10% | 降低科研门槛，让缺乏资源的个体研究者也能获得「科研助理」级别的辅助 |

## 答辩时必讲的三个原创亮点

1. **不是问答机器人，是科研操作系统**：五个 Agent 各司其职，把「人做综述」的完整流程自动化。
2. **让 AI 思考可见**：传统 AI 是黑盒，本项目的「思考流」把规划、检索、评审每一步实时摊开给用户，既提升信任，也体现「人机协同」。
3. **发现研究空白，而不只是总结**：通过汇总 Limitations 章节 + 争议检测，输出「未来可研究方向」，这是从「检索」到「洞察」的跨越。

## 与参考开源项目的差异化

| 参考项目 | 借鉴了什么 | 我们的差异化 |
|---|---|---|
| academic-research-assistant | 多智能体分工思想 | 实时思考流可视化 + 完整前端产品化 |
| RLM-Agent | 证据分级思路 | 分级结果与知识图谱联动展示 |
| browser-ai-research-agent | 浏览器/网页检索交互 | 聚焦学术场景，接入 ArXiv + 向量库 |
| JARVIS | 评审/可信度评估机制 | 争议检测 + 研究空白挖掘 |

> 说明：架构思路有所借鉴，但**代码全部原创**，且通过「思考流可视化」与「研究空白挖掘」形成独立创新点。
