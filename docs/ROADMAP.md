# 8 周备赛冲刺路线图

> 目标节点：**省赛 2026 年 11 月 29 日**。当前已完成「可运行骨架」（MVP-0）。

## 现状（核心能力已全部完成）

- ✅ 多 Agent 五阶段流水线（规划/检索/阅读/评审/撰写）
- ✅ CRAG 自我修正检索
- ✅ 研究空白挖掘
- ✅ 本地知识库（txt/md/pdf 上传 + BM25 检索）
- ✅ 自主工具调用（计算器/时间/ArXiv）
- ✅ 人机协同（中途插入指令 / 中断）
- ✅ 玻璃态驾驶舱 UI + 思考流可视化 + 知识图谱 + 报告
- ✅ ArXiv 真实检索 + SSE 流式传输 + Mock/DeepSeek 双模式

## 冲刺计划

### Week 1-2：基础夯实
- 接入 **ChromaDB** 本地向量库（Docker 运行）
- 实现 **PDF 上传 → 切片 → 向量化** 完整链路
- 补齐 `reader.ts` 的 PDF 全文解析（替换摘要输入）

### Week 3-4：AI 深度攻坚（重点）
- 用 **LangGraph.js** 重写编排层，构建显式状态图
- 实现 **CRAG 自我修正**：检索相关性低时自动重写查询词重试
- 实现**混合检索**：BM25 + 向量（提升召回）
- 规划/评审 Agent 接入真实大模型（DeepSeek）

### Week 5：UX 打磨
- 知识图谱升级为 **D3.js 力导向图**（可拖拽）
- 优化流式动画与「人机协同」交互（研究中途可插入指令）
- 深色/浅色主题切换

### Week 6：系统整合
- 接入 **MCP 工具调用**（浏览器、数据库等可选加分项）
- 部署 Staging 环境（Vercel + Railway 跑 ChromaDB）
- 全流程异常处理与降级

### Week 7：测试与文档
- 找非技术人员测试，修复体验 Bug
- 撰写 ≤30 页技术文档（重点：AI 选型理由 + 优化策略 + 评分对照）

### Week 8：演示与答辩
- 录制 7 分钟高清演示视频（普通话讲解，展示复杂研究场景）
- 准备答辩 PPT，突出三大原创亮点（见 [评分对照](COMPETITION.md)）
